# Proceso estándar v1 · referencia conservada

Objetivo: producir una entrega local trazable. Aplicable a módulos de Panviz. Roles E1 coordinación, E2 requisitos/usuario simulado, E3 desarrollo, E4 calidad y E5 configuración/medición. Los nombres y compromisos reales se registran antes de aprobar baselines.

1. Diagnosticar necesidad, tres brechas y riesgos; acordar alcance.
2. Definir requisitos con criterios y responsable; comparar alternativas; preparar datos y oráculo; revisar B0.
3. Adaptar el proceso: para CSV se revisa contrato de columnas; para formulario se revisa contrato de campos. Registrar excepción razonada sin omitir trazabilidad.
4. Implementar por módulos, revisar por persona diferente del autor y ejecutar las seis categorías mínimas de prueba.
5. Registrar CR01 antes de habilitarlo en la entrega; evaluar impacto, decisión E1, implementación y séptima categoría de prueba con regresión.
6. Validar un escenario completo con E2, revisar calidad con E4, medir con E5 y registrar resultados reales.
7. Liberar B2 con etiqueta v0.1 y repetir desde una copia limpia por otra persona.

Cierre de actividad: artefacto identificado, revisión nominativa, fecha, versión y evidencia. Los resultados que no se ejecutaron se marcan pendientes. No se aprueba el propio código. Las plantillas se reutilizan y se rellenan únicamente con observaciones reales.

Esta versión se conserva como referencia de diseño; no afirma una aprobación o capacitación ya ejecutada.
